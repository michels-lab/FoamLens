## Additional master-spec coverage verified

- Discovery is field-name agnostic and supports scalar/vector/tensor families, dimensions, boundaries, arbitrary postProcessing outputs and dictionaries.
- Multi-region context is explicit and region names are discovered rather than assumed.
- Data Catalog distinguishes native/derived provenance and dimensions/units.
- Temporal comparison supports Native, Common Time Grid and Reference Case Grid; Linear/Nearest alignment never extrapolates by default.
- Difference analysis covers signed, absolute, relative, percent, RMSE, MAE, maximum absolute difference and correlation.
- Numerical Performance keeps linear-solver residuals separate from PIMPLE/SIMPLE/PISO coupling.
- Field Mapping is user-overridable and region-aware.
- Phase, momentum, ratios, Pearson/Spearman, derived-field verification, thermal, flow, gradients, solidification/remelting and energy-balance provenance are capability-driven.
- Missing data remains unavailable rather than being fabricated or zero-filled.
- Large-project architecture has lazy profile hydration, in-memory reuse/cache, incremental parsing, cancellation and progress.
- Spatial Profiles playback uses one physical-time clock for multi-case comparisons and does not reread profile files on each frame.
- Export metadata records case/region/field/time/alignment/statistics provenance.
- Product-code fixture guard rejects QuickCup and controlled-case names in frontend product code.

## Visual regression note

The v1.3.0 gate is a runtime visual smoke test rather than pixel-perfect golden-image comparison. CI launches both the portable executable and the installed executable under WebView2, validates key rendered controls and duplicate DOM IDs, captures PNG previews, and fails on missing/hidden/empty launch UI. The screenshots are retained in the Windows workflow artifact for reproducible inspection.
