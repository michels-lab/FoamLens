## Direct observation
Original Time Series 3D history building is already implemented in `v14-zz-field-workspace.js`: it reads actual OpenFOAM fields at source physical time, samples field scalar/vector components and probes, or samples original postProcessing spatial profile rows. Both history slots are prepared as drafts and atomically committed only after successful completion; T2 cancel advances `fwState.fieldTsSeq` and prevents stale commits. The permanent T2 status nevertheless said *progress is not reported by this engine*, and users had no observable data-provenance counts while a potentially large case was read.

## G52 narrow implementation
- In the **existing** original `v14-zz-field-workspace.js`, one source-owned `fwFieldTsReportProgress(slot,completed,total,seq)` reports **actual inspected source frame/row counts** after each valid source read. Both OpenFOAM global field history and pinned Probe history use the original `fwPhysicalTimes(group.times)`, and profile history uses original profile rows sorted by physical time. No new frame parses, synthetic values, guessed time/case/field units, or scientific algorithms. Counts reflect inspected frame entries, not necessarily finite plotted points or real elapsed-time percentage.
- Preserve the source atomic commit, two slots, original parser, native `fvLoadFrameData`, error handling, existing `fwState.fieldTsSeq` cancellation. Throttle events to approximately 24 intermediate UI updates per source. Never dispatch after a cancelled generation or for invalid counts/slots.
- In the **same original** T2 panel `v24-granada-timeseries-t2.js`, replace misleading no-progress warning with the original per-source `foamlens-field-history-progress` event. Display `Series N: x / y original source steps inspected` / `Serie N: x / y pasos originales de fuente revisados`; do not display invented %, ETA, processed point validity, or solver iteration estimates. Keep build busy state independent from source-progress text, so the current status MutationObserver does not cancel a running build on frame updates. Real cancel clears progress; late stale events cannot return.
- Extend existing owner `desktop/tests/granada-176-timeseries-ui.spec.cjs` with real original-source helper execution and adversarial invalid-count / stale-epoch / source-path checks, plus simulated DOM live progress, cancellation, language switch, two independent slots. No new global UI themes, CSS patches, parsers or data conversion.
