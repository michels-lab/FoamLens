Time Series is already a fifth actual source-owned capture. Each variant (Installed, Portable) and viewport (wide, compact) needs five distinct PNGs: **20 additional** and **36 slots total**.
- Field Compare is not inferred from a generic 3D/2D split: the host activates the original `fcEnabled` side-by-side control and validates `fcViewport`, `fvViewport`, both original canvas elements, Compare ownership state, and an actual Field workspace.
- Analysis, Review and Live use actual Ribbon actions, assert their owned visible panels and controls before calling the original `CaptureCdpPngAsync`. Failures produce a small bounded **boolean-only** contract; no raw QuickCup case path, cell values, renderer error text or numerical scientific data is emitted.

The Windows build only requires 20 originals when it actually has B13; the strict G5 offline reviewer independently marks missing originals `INCOMPLETE`.

The existing G5 UI review source CI is extended to run the new guards on Windows and Ubuntu.
