About the project

About FoamLens

OpenFOAM analysis, diagnostics and scientific visualization.

FoamLens is a browser-based OpenFOAM analysis workspace for discovering simulation outputs, exploring scientific data, diagnosing numerical behavior, comparing cases, reviewing findings, and producing publication-ready figures from one place.

From simulation data to evidence you can inspect.
